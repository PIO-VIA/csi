CONTEXTE DU PROJET
==================
Tu travailles sur "CSI Sécurité Sociale", une application Next.js 16 (App Router, TypeScript, Tailwind CSS v4) pour la gestion d'une caisse de sécurité sociale au Cameroun. Le design system est basé sur une palette bleue institutionnelle (primary-*, accent-*, slate-*), polices Plus Jakarta Sans (display), DM Sans (body), JetBrains Mono (mono). Le projet utilise framer-motion, lucide-react, react-hook-form + zod, react-i18next (fr/en), recharts, @radix-ui (Dialog, DropdownMenu).

Il y a 3 espaces : Admin (/admin/*), Médecin (/medecin/*), Assuré (/assure/*), avec sidebar, topbar, cards, tables, modals déjà en place.

OBJECTIF GÉNÉRAL
================
Améliorer significativement le design UI/UX de l'ensemble de l'application sans casser la logique métier existante (appels API, lib/api.ts, lib2/*, authContext, types). Travaille de façon itérative, écran par écran, en gardant la cohérence du design system existant (couleurs primary/accent/slate/success/danger/warning/info définies dans app/globals.css).
